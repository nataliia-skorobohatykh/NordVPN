# Mid QA Engineer Assessment task

##### Duration: 40 to 45 mins

Welcome. 

If you are reading this README file then it implies that you've opted for a live assessment on the Mid QA Engineer role for our project. Feel free to ask questions or raise discussions, we will answer. Time, however, is limited and the challenge may require you to estimate your efforts effectively.

Good luck. 

Challenge: A visitor to the [NordVPN Dark Web Monitor landing page](https://nordvpn.com/features/dark-web-monitor/) is able to download the NordVPN app from the footer section. The user will need to choose the relevant platform and then proceed to the corresponding download page.

Implement and include a test that covers the user navigation from landing page to NordVPN app to download page for the 
+ __Linux__ platform.
+ __Android__ platform.

The implemented test will need to run for both desktop and mobile viewports, for __desktop__ use Chrome, Firefox and Safari. For __mobile__, you can skip Safari and Firefox.

Feel free to ask any questions.
